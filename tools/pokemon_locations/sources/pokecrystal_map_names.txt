# Catálogo de nombres simbólicos de mapas — Pokémon Crystal (Johto + Kanto)
#
# Origen: nombres de constantes MAP_* confirmados a través de búsqueda web
# sobre el repositorio público de pret (pokecrystal), cruzados con el orden
# geográfico real del juego (ampliamente documentado y estable).
#
# IMPORTANTE — qué SÍ y qué NO está verificado aquí:
#   SÍ: que estos nombres de mapa existen en el juego y el orden geográfico
#       en el que aparecen (esto es contenido de juego público y muy estable).
#   NO: el número de grupo/mapa (group, id) que la memoria RAM usa para cada
#       uno. Eso vive en constants/map_constants.asm, que todavía no se pudo
#       obtener. Por eso este archivo es solo texto plano con nombres, no
#       una transcripción del .asm real (no se inventan bytes de atributos,
#       tilesets ni conexiones que no se verificaron mapa por mapa).
#
# El generador (generate_locations.py) usa este archivo para el catálogo de
# NOMBRES + tipo de ubicación (ciudad/ruta/cueva/etc., inferido del nombre).
# La resolución a Map<int, PokemonLocation> solo ocurre para los símbolos que
# tengan un ID numérico confirmado en sources/map_constants.asm (ver ese
# archivo — hoy está vacío, pendiente de conseguir).
